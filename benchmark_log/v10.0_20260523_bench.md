### 5.4 热点摘要

| 占比（约） | 符号 / 函数 | 说明 |
|------------|-------------|------|
| ~4.3% | `onHttp` → `ThreadPool::enqueue` → `futex_wake` | I/O → worker 投递 |
| ~4.1% | `sendHttpOnLoop` → `bufferToSck` → `write` | 写回 I/O 线程 + syscall |
| ~3.9% | 内核 TCP / softirq | loopback 网络栈 |
| ~8.8% | `[k] _raw_spin_unlock_irqrestore` | futex 与网络路径 |

**用户态结论：** 最热为 **HTTP 双跳跨线程** 与 **写 socket**；Echo 下解析不在栈前列。

### 5.5 perf report 摘录

```text
~4.34%  EventLoop::loop → onHttp → ThreadPool::enqueue → futex_wake
~4.09%  sendHttpOnLoop → bufferToSck → write → tcp_sendmsg → softirq
```

## 7. 结论与下一步

- **v10.0 验收**：短连接轻量用例 SSH 稳定；KA 主基线 **~32.8k RPS**。
- **perf**：符号可解析；热点为 **enqueue 双跳** 与 **写路径**。
- **v10.1**（须 src 变更后升版）：I/O 直出静态 GET、写路径减拷贝、ThreadPool 唤醒优化。
- **下一步**：实施 v10.1 代码 → 新建 **v10.1** 测试报告并 wrk 复测。
