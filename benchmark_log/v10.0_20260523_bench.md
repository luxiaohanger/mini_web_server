## 6. 分析结果

- **wrk**：KA 正式基线 **32820 RPS**（第 4 节 -t2 -c20 -d30s）；相对 v9 **29154（+12.6%）**；close -t1 -c5 **3652 RPS**。
- **符号 §0**：**kernel 60%**、**libc 26%**、**server Self 10%**、**libstdc++ 3%**——不能只看 src Self；用户态合计约 **39%**。
- **符号 §1**：All 最热 **EventLoop::loop(62%)**、**onHttp→sendHttpOnLoop(~33%)**、**ThreadPool worker(22%)**；**enqueue 双跳**（enqueue 9.8% + handler 15.1%）与 **TimerQueue::refreshClock(7.3%)** 为 src 侧可优化点；`HttpProcess::parse` All 4.5% 非主瓶颈。
- **符号 §2**：**other 36%**（锁/原子 `_raw_spin_unlock_*` 合计 ~13%）+ **network 13%**；loopback 仍以内核锁与 TCP 栈为主；nf_conntrack / AppArmor 有少量开销。
- **符号 §3**：**pthread 6.2%**（future/once）与 **io 4.6%**（write 4.5% + readv 4.3% 符号级）分离；**timer 2.8%**、**epoll 1.8%** 对应 idle 刷新与 Channel 管理；**alloc 1.1%**。
- **综合结论**：瓶颈在 **内核 loopback + 锁/原子**、**ThreadPool enqueue/future 包装** 与 **TimerQueue idle 刷新**；v10.1 优先 I/O 直出（减 enqueue 双跳）、写路径减拷贝、Timer 刷新降频或合并。
- **异常**：close -t1 -c10 **read 3**；perf 同跑 wrk **41510 RPS**（第 5.2 节，预期，不作验收）。
- **下一步**：v10.1 src 变更 → 新建报告；`bash scripts/perf_bench.sh flamegraph -v v10.0` 可重生符号表与 SVG。
